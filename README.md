# 다해랑 💕

다해랑 함께한 데이트·여행을 기록하고, 앞으로 할 데이트와 버킷리스트를 모아두는 커플 앱입니다.
설치형 웹앱(PWA)이라서 빌드 과정 없이 폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 기능
- **홈**: 함께한 날(D+), 다가오는 기념일(100일 단위, 주년, 생일, 직접 추가한 기념일), 다음 데이트 D-day, 위시 달성률, "오늘은 이거 어때?" 추천, N년 전 오늘의 추억
- **캘린더**: 월 달력(좌우로 넘기기), 추억·계획·기념일 표시, 사진이 있는 날은 사진이 배경으로 깔림, 날짜를 눌러 추억 기록이나 일정 추가
- **위시**: 카테고리(데이트/여행/맛집·카페/사소한 것/버킷리스트), 빠른 추가, 체크하면 하트가 터지고 바로 "추억으로 남기기"로 이어짐
- **추억**: 월별 타임라인 / 사진 앨범 보기, 데이트·여행(몇 박 며칠) 구분, 기분 이모지, 메모, 사진 최대 10장(자동 압축)
- **설정**: 두 사람 프로필 사진·이름·생일, 사귄 날, 1일부터 셀지 0일부터 셀지, 테마 색 5가지, 백업 파일 만들기/불러오기

## 내 컴퓨터에서 실행
```bash
python -m http.server 5173
```
브라우저에서 http://localhost:5173 을 열면 됩니다.

## 폰에 설치하기
앱으로 설치하려면 HTTPS 주소가 필요합니다. 무료로 하는 방법 두 가지:
1. **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 주소가 생깁니다.
2. **GitHub Pages**: 이 폴더를 GitHub 저장소에 올리고 Settings → Pages를 켜면 됩니다.

주소가 생기면 폰에서 그 주소를 엽니다.
- iPhone: **Safari**에서 열고 공유 버튼 → **홈 화면에 추가**
- Android: Chrome에서 열고 메뉴 → **앱 설치** (또는 홈 화면에 추가)

> 데이터는 그 폰 안(IndexedDB)에만 저장됩니다. 주소가 바뀌면 데이터가 따로 저장되니까 주소는 하나로 정해서 쓰세요.
> 가끔 설정 → **백업 파일 만들기**로 백업해두는 걸 추천합니다.

## 수정한 뒤 다시 배포할 때
`sw.js` 맨 위의 `VERSION` 값을 올려야 폰에 새 버전이 확실히 반영됩니다.

## 나중에: 다해 폰이랑 동기화
지금 구조는 동기화를 붙이기 쉽게 만들어져 있습니다.
- 모든 기록에 `id`(uuid), `createdAt`, `updatedAt`, `deleted`(삭제 표시)가 있어서 "더 나중에 수정된 쪽이 이김" 방식으로 바로 합칠 수 있습니다. 백업 불러오기도 이미 이 방식으로 합칩니다.
- 저장은 `js/app.js`의 `saveRec` / `removeRec` / `saveProfile`과 `js/db.js`를 거치므로, 여기에 Supabase나 Firebase 호출을 붙이면 됩니다(사진은 Storage 버킷).
- 그 전까지는 백업 파일을 카톡으로 보내서 서로 불러오면 내용이 합쳐집니다.
